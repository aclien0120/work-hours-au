設定 App PIN

第一次使用 v6，請設定 4–6 位數 PIN。之後開啟 Work Hours AU 時會先要求解鎖。

PIN 不會上傳到 GitHub，也不會包含在備份檔中。若你直接從 iPhone「檔案」開單檔測試版，iOS 可能使用臨時儲存；正式使用請以 GitHub Pages HTTPS 版本為準。

App PIN

PIN 只用來保護這台裝置上的 App。PIN 本身不會上傳 GitHub，也不會寫入匯出的 JSON 備份。

如果忘記 PIN，只能重設 App 本機資料；有備份的話可在重設後再匯入。
